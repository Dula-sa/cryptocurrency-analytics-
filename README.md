# Crypto Analytics Dashboard (2015–2025)

## 📌 Project Overview
This interactive Power BI Dashboard analyzes multi-asset cryptocurrency performance, trading volume behaviors, historical price trends, and cross-asset correlations across a 10-year dataset (2015–2025). 

The goal of this analysis is to translate complex financial metrics—including Average Daily Returns, Price Volatility (%), 7-day/30-day rolling averages, and Pearson correlation coefficients—into actionable visual insights.

## 🛠️ Tools & Technologies Used
- **Business Intelligence & Visualization:** Microsoft Power BI
- **Data Transformation & Modeling:** Power Query & Star Schema Architecture
- **Calculations & Statistics:** Data Analysis Expressions (DAX)
- **UI/UX Design:** Custom Dark-Themed Executive Layout with Page Navigation

## 🔑 Key Insights & Features
- **Market Overview:** High-level KPIs tracking total symbols, average volatility, average return, and cumulative market volume alongside monthly trend lines.
- **Individual Asset Deep Dive:** Dynamic tracking of 7-day and 30-day rolling averages, daily returns, and volume vs. volatility comparisons across individual tokens.
- **Comparative Asset Analysis:** Side-by-side tradeline evaluations and performance rankings highlighting top gainers, losers, and multi-token metrics.
- **Cross-Asset Correlation:** Advanced custom DAX-driven Pearson correlation matrices examining linear dependencies across major crypto assets.
